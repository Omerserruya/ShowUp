# ShowUp mobile app

The ShowUp owners' app (Android; iOS later): a Capacitor shell around
https://showup-rsvp.com with push notifications. The app code lives in `mobile/`;
`.github/workflows/android-apk.yml` builds the APK on every push.

Newest APK: https://github.com/Omerserruya/ShowUp/releases/latest/download/ShowUp.apk
