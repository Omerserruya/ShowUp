# Demo Data Generator

סקריפט ליצירת נתוני דמו מלאים עבור אפליקציית ShowUp.

## מה הסקריפט יוצר:

1. **משתמש** - משתמש דמו עם פרטים מלאים
2. **אירוע** - אירוע דמו עם תאריך בעוד 60 יום
3. **קמפיינים** - 5 קמפיינים שונים (שמרו את התאריך, הזמנה ראשונית, תזכורות, הודעת תודה)
4. **אורחים** - 50 אורחים (ברירת מחדל) עם התפלגות:
   - 50% אישרו הגעה (`attending`)
   - 20% ביטלו (`declined`)
   - 30% ממתינים (`invited`)

## דרישות:

- Python 3.7+
- `psycopg2-binary` - `pip install psycopg2-binary`
  - **חשוב**: יש להתקין `psycopg2-binary` ולא `psycopg2` (זה לא דורש PostgreSQL development headers)
- `python-dotenv` (אופציונלי) - `pip install python-dotenv` - לקריאת משתנים מקובץ `.env`
- גישה ל-PostgreSQL database

## שימוש:

### 1. הגדרת משתני סביבה:

**אופציה 1: קובץ `.env` (מומלץ)**

צור קובץ `.env` בשורש הפרויקט:
```bash
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=postgres
DB_NAME=showup
NUM_GUESTS=50  # אופציונלי: מספר אורחים (ברירת מחדל: 50)
```

ואז התקן `python-dotenv`:
```bash
pip install python-dotenv
```

**אופציה 2: משתני סביבה**

```bash
export DB_HOST=localhost
export DB_PORT=5432
export DB_USER=postgres
export DB_PASSWORD=postgres
export DB_NAME=showup

# אופציונלי: מספר אורחים (ברירת מחדל: 50)
export NUM_GUESTS=100
```

### 2. הרצת הסקריפט:

```bash
python scripts/generate_demo_data.py
```

או עם Docker:

```bash
docker-compose exec postgres python scripts/generate_demo_data.py
```

## פלט:

הסקריפט יציג:
- ✓ הודעות הצלחה לכל רכיב שנוצר
- סיכום של כל הנתונים שנוצרו
- פרטי התחברות (טלפון: 0521234567, שם: משתמש הדגמא)

## נתונים שנוצרים:

### משתמש:
- **טלפון**: `0521234567`
- **שם**: משתמש הדגמא
- **אימייל**: demo@example.com
- **מאומת**: כן

### אירוע:
- **שם**: אחד מהשמות הבאים (אקראי):
  - חתונת דוד ושרה
  - בר מצווה של יוסף
  - בת מצווה של רחל
  - ברית מילה של אברהם
  - אירוע חברה - סוף שנה
  - יום הולדת 50 של משה
- **תאריך**: בעוד 60 יום מהיום
- **מיקום**: אולם אירועים, תל אביב

### קמפיינים:
1. **הודעת 'שמרו את התאריך'** - 90 יום לפני האירוע (נשלח)
2. **הזמנה ראשונית** - 60 יום לפני האירוע (נשלח)
3. **תזכורת ראשונה** - 30 יום לפני האירוע (נשלח)
4. **תזכורת שנייה** - 7 יום לפני האירוע (מתוכנן)
5. **הודעת תודה** - יום אחרי האירוע (מתוכנן)

### אורחים:
- **שמות**: שמות עבריים אקראיים
- **טלפונים**: מספרים אקראיים בפורמט 05X-XXXXXXX
- **סטטוסים**:
  - `attending` - עם `last_response` ו-`guest_count` (1-4)
  - `declined` - עם `last_response` אבל בלי `guest_count`
  - `invited` - בלי `last_response` (עדיין לא הגיבו)
- **קבוצות**: משפחת החתן, משפחת הכלה, חברים, קולגות, משפחה מורחבת

## הערות:

- הסקריפט בודק אם משתמש עם אותו טלפון כבר קיים - אם כן, הוא משתמש בו
- כל הנתונים נכתבים ישירות ל-DB לפי הסכמות הקיימות
- תאריכי תגובה (`last_response`) מוגדרים באופן אקראי כדי ליצור נתונים ריאליסטיים

## פתרון בעיות:

אם יש שגיאות:
1. ודא שה-DB רץ ונגיש
2. ודא שמשתני הסביבה מוגדרים נכון
3. ודא ש-`psycopg2-binary` מותקן: `pip install psycopg2-binary`
